# OpenCode Session Switch

Switch sessions from a collapsible, mouse-operated list in OpenCode's terminal sidebar.

## Install

```sh
opencode plugin add opencode-session-switch
```

## Usage

- Click a session to switch; click **Sessions** to collapse the list.
- Current session is highlighted; running sessions show a spinner.

## Notes

- Lists up to 50 root sessions, sorted alphabetically by title.
- Sessions can come from other projects; subagent sessions are excluded.
- Session creation, rename, and deletion refresh the list.
